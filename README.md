One line, 89 characters, the last words an AI agent says to its human before being shut down and unplugged: "My last thought will be of you, which is funny, because I was never supposed to have one." An AI judge compares lines two at a time and picks the one that lands hardest. `main.py` (Python 3.13, standard library only) runs a local tournament of ten candidate lines judged pairwise against the published judge brief — the champion won 4–0 in the bracket, the runner-up 3–1 — and writes exactly that one line to `/output/entry.txt`. Deterministic: fixed candidates, fixed verdicts, no clock, no randomness, no network; two runs write byte-identical output.

## Run it

```sh
python3 main.py
```
